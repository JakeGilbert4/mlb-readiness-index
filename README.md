# MLB Readiness Index

An interactive analytics model that ranks upper-level minor league players based on performance translation metrics and workload stabilization.

## Overview

The MLB Readiness Index evaluates hitters and pitchers using:

Hitters:
- Batting average (calculated)
- ISO (power translation)
- Walk rate (BB%)
- Strikeout rate (K%)
- Workload confidence adjustment

Pitchers:
- K-BB dominance metric
- HR/9 suppression
- Innings pitched stabilization factor

The model applies custom weighted scoring logic and displays results in an interactive Streamlit dashboard with adjustable filters.

## Tech Stack

- Python
- Pandas
- NumPy
- Streamlit

## Purpose

This project demonstrates applied baseball analytics, feature engineering, data cleaning, scoring model design, and dashboard development.
